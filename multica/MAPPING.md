# Multica Mapping

Multica is the Agent Execution Control Plane; FDI owns semantics/contracts/Skills/gates.

| FDI concept | Multica object | Boundary |
|---|---|---|
| Product-scoped FDI instance | Project | runtime/UI container, not canonical artifact |
| Product onboarding/bootstrap | Parent Issue + bounded tasks | no silent Asset publication |
| PA maintenance run | Issue/Task using root PA Skill | emits proposals/maintenance output |
| One Agent execution | Task | task complete != semantic gate |
| Stable specialist | Agent | runtime/model/Skill binding |
| Reusable governed method | Skill | FDI semantic procedure |
| Dynamic routing | Squad | leader routes work |
| Incremental maintenance trigger | Autopilot | enable after bootstrap is stable |
| New feature | Issue/context | Layer 1 remains T1–T4 governed |

Recommended Product Intelligence squad:

- FDI Product Intelligence Lead
- FDI Codebase Intelligence Agent
- FDI Product Semantics Agent
- FDI Delivery History Agent
- FDI Product Intelligence Reviewer
